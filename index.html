⚙️ Сначала настрой Firebase (разово, 5 минут)

1
Перейди на firebase.google.com → Get started → Создай проект
2
В проекте: Build → Realtime Database → Create database → Start in test mode
3
Project Settings (шестерёнка) → Your apps → </> Web → скопируй firebaseConfig
4
Замени в index.html (строки 18–26) значения apiKey, databaseURL и т.д. на свои
5
Загрузи файл на GitHub Pages или Netlify Drop (просто перетащи файл)
